Two documents disagree. Which one still counts?

Pick a question about the sample college handbook. Palimpsest finds the passages and decides which ones were written over. Then it shows what the answering model is allowed to see. When it cannot tell it says so.

This page replays a real run. The gate and the retriever are the project code. The Decider 2B scores were recorded on my laptop. To ask your own questions run the project locally with the steps in the GitHub repo.

    All documents are fictional. Answers are for information only.

    Privacy

    This page is static. It has no form and sends nothing anywhere. It sets no cookies and loads nothing from other sites.

    GitHub hosts the page and may keep its own server logs under its own terms.

    The full project runs on your own computer. There the decision model and the server stay on 127.0.0.1 and the server keeps no question logs.
